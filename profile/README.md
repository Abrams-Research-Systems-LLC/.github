# Abrams Research Systems LLC

Abrams Research Systems LLC is a U.S. small business formed in 2026 and based in Loveland, Colorado. It develops and evaluates deterministic state-record software for constrained embedded systems. Joshua M. Abrams is Founder and Principal Investigator. The company holds CAGE code 25CH7 and UEI J3B7R2FBHMA3, with an active SAM.gov registration.

AEA-STATE/1 (Abrams Event Address) is a published specification and `#![no_std]` Rust reference library with a C ABI. It defines a fixed 136-byte record that tags an estimated state with a reference frame and a time scale, plus an unkeyed SHA-256 integrity digest for detecting accidental corruption. Readiness is TRL 3: a host-verified proof of concept with no hardware or flight demonstration yet.
